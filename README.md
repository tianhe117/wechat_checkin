# 企业微信自动任务工具

通过手机网页安排 Android 手机上的企业微信定时操作，支持手动执行、截图核对、历史记录和 Bark 通知。适用于打开目标应用后即可触发预期业务流程的个人使用场景。

Windows 控制端通过 ADB 操作手机，Linux 管理端负责网页、计划和记录，两端通过局域网 HTTP API 通信。工具记录手机操作是否完成，实际打卡结果由用户查看截图确认。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 自动计划 | 设置每周执行日及上班、下班时间窗口，随机生成并保存执行时刻 |
| 日期调整 | 单日或批量设置默认、打卡、请假，支持暂停和恢复自动任务 |
| 手动操作 | 完整应用流程、当前界面截图和手机连接测试 |
| 执行记录 | 按日期分页查看计划时间、实际时间、步骤、状态、错误与截图 |
| 连接监测 | 查看控制端与手机状态，设备状态变化时提醒 |
| Bark 通知 | 发送执行结果和设备提醒，支持测试及重发 |
| 手机管理 | 手机页面、主屏幕入口、账号密码及应用和设备设置 |

完整应用流程为：亮屏 → 解锁并返回桌面 → 关闭并启动目标应用 → 等待 → 截图 → 返回桌面 → 关闭应用 → 锁屏。

计划和任务状态保存到 SQLite。断线或重启后按原请求编号确认结果，失败、错过和结果未知的操作由用户决定是否再次执行。所有业务时间采用北京时间（UTC+8）。

## 项目结构

```text
wechat_checkin/
├── controller/                 Windows 手机控制服务
│   ├── main.py                 ADB 操作、请求存储与 HTTP API
│   ├── config.example.json     控制端配置示例
│   ├── script/                 启动脚本
│   └── README.md               安装、启动和数据维护
├── manager/                    Web 管理与业务调度服务
│   ├── main.py                 服务入口
│   ├── src/                    计划、任务、存储、API 客户端与页面路由
│   ├── templates/              Jinja2 页面
│   ├── static/                 样式、脚本与图标
│   ├── tests/                  HTTP 契约与业务测试
│   ├── Dockerfile              管理端运行依赖镜像
│   ├── compose.yaml            Docker Compose 部署
│   └── README.md               部署、首次设置和数据维护
└── docs/                       需求、架构与两端设计
```

两端使用 Python、Flask、Waitress 和 SQLite，管理端使用 Jinja2 渲染页面。每端运行一个服务实例，各自保存配置和数据。ADB、虚拟环境、真实配置、数据库、截图和日志在本机安装或生成，不提交 Git。

## 运行环境与使用入口

| 组件 | 运行要求 |
| --- | --- |
| Android 手机 | USB 连接 Windows，启用并授权 ADB 调试，解除锁屏密码，安装目标应用 |
| 控制端 | Windows、Python 3.12、Android Platform-Tools，默认端口 `8765` |
| 管理端 | Linux Docker，默认端口 `8000`，HTTPS 反向代理由用户自行配置 |
| 网络 | 管理端可访问控制端；浏览器可访问管理端，Bark 按需接入 |

1. 按[控制端说明](controller/README.md)安装 ADB 和 Python 环境，初始化配置并启动服务。
2. 按[管理端说明](manager/README.md)部署管理端，首次登录密码为 `tianhe`，可在账号设置中修改。
3. 在设备设置中填写控制端地址与 API key，选择或填写设备序列号，也可留空使用控制端选择规则；完成连接测试。
4. 设置应用参数、每周计划和日期覆盖，按需配置 Bark 通知。

管理端长期保存业务记录和截图，控制端保存请求去重账本；部署和迁移时需持久化两端数据目录。

管理端通过 Docker 挂载宿主 `manager/` 目录运行，普通代码更新后重启容器即可；运行依赖变化时重新构建镜像。具体命令见[管理端说明](manager/README.md)。
